Understanding API & REST Architecture

What is an API?

API (Application Programming Interface) is an interface that allows two software applications to communicate. Examples: Weather App, Payment Gateway.

Client → API Gateway → Backend Server → JSON Response

What is a REST API?

REST API is an architectural style using HTTP methods, URLs, JSON payloads, and stateless communication.

GET /api/v1/users | POST /api/v1/users

1. Introduction

AYAKA API provides enterprise-grade RESTful endpoints designed for high concurrency, reliable database persistence via PostgreSQL, and secure API Key validation.

2. Base URL

All API requests must be directed to the production Vercel deployment URL:

https://your-domain.vercel.app/api/v1

3. Authentication (API Key)

Include your unique API Key with the x-api-key header in every request.

# Example cURL Request

curl -X GET "https://your-domain.vercel.app/api/v1/users" \

-H "x-api-key: AYK_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

Backend & Vercel Code Architecture

Complete production Node.js/Express serverless handlers and PostgreSQL schema.

/api/v1/users.js (Vercel Serverless Function) 
const { Pool } = require('pg');
const pool = new Pool({ connectionString: process.env.DATABASE_URL });

module.exports = async (req, res) => {
    const apiKey = req.headers['x-api-key'];
    if (!apiKey || !apiKey.startsWith('AYK_')) {
        return res.status(401).json({ success: false, message: 'Unauthorized API Key' });
    }

    if (req.method === 'GET') {
        try {
            const { rows } = await pool.query('SELECT id, username, email FROM users LIMIT 50');
            return res.status(200).json({ success: true, data: rows });
        } catch (err) {
            return res.status(500).json({ success: false, error: err.message });
        }
    }
    return res.status(405).json({ success: false, message: 'Method Not Allowed' });
};
